# Portif Bourse

## Présentation

Portif Bourse est un projet d'application de gestion de portefeuille boursier. Son objectif est de permettre à un utilisateur de consulter les valeurs qu'il détient, leur montant et leurs plus-values ou moins-values latentes, ainsi que de suivre l'évolution et la répartition de son portefeuille. L'application doit également permettre de saisir et de consulter les transactions d'achat et de vente.

Dans un premier temps, ce projet est développé pour mon usage personnel.

## Installation et configuration de la méthode BMAD

Pour installer et configurer la méthode BMAD dans ce projet, exécuter les commandes suivantes à la racine du dépôt :

```bash
npx bmad-method install
npx skills add bmad-code-org/BMAD-METHOD --skill '*'
```
